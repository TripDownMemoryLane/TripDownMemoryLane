# TripDownMemoryLane
Trip Down Memory Lane（記憶花園） 是一個為長者與家人設計的多媒體回憶輔助系統。<br />
使用者可以上傳照片，透過 AI 生成回憶故事，並進一步產生結合圖片與語音的互動式測驗，協助長者進行回憶與認知刺激。<br />
本專案包含 前端（React） 與 後端（Express API），並以 單一 GitHub repository（monorepo） 方式整合，作為期末專題繳交版本。

## 📁 專案結構
```
TripDownMemoryLane-final/
├── frontend/   # 前端（React + TypeScript）
├── backend/    # 後端（Express API，AI 故事與測驗生成）
└── README.md   # 本說明文件
```
